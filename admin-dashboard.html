Super Admin Operational Guide & FAQs

1. RB & PGRC Coordination Policy

A complaint has exactly ONE canonical Case ID. When both Regulation Bureau (RB) and Grievance Cell (PGRC) need to coordinate, assign one unit as Primary Owner and the other as Supporting Unit. Do not create duplicate complaint records for multi-bureau cases.

2. Sequential Workflow Lifecycle

Permitted transitions: RECEIVED → UNDER_REVIEW → PENDING_ASSIGNMENT → IN_PROGRESS → AWAITING_INSTITUTION_RESPONSE → AWAITING_INTERNAL_REVIEW → RESOLVED → CLOSED. Overdue is an SLA calculation metric based on 45 days, not a replacement status.

3. Bulk Data Import Idempotency

CSV imports validate institution permanent IDs and duplicate source IDs. Ingestion batches record row-level errors without silently failing or discarding records.
